# 算法说明

本文说明当前实现的处理流程及其工程含义，帮助审阅者理解代码，不把原型结果误认为计量结论。

## 输入校验

程序支持 SPE、XLSX、CSV 和 TXT。输入在进入算法前会转换为一维浮点数组，并检查：

- 通道与计数长度相同且非空；
- 数值有限，计数非负；
- 通道顺序单调，重复通道合并；
- SPE 的 `$DATA` 优先按闭区间解释；对于部分导出器使用的上界写法，在实际点数恰好少 1 时兼容读取并记录警告；
- SPE 的 `$MEAS_TIM` 按“活时间、实时间”顺序读取。

## 本底扣除

`snip_baseline` 在对数变换域内迭代比较局部值与对称邻点均值，用于估计缓慢变化的连续本底。净谱按 `max(counts - baseline, 0)` 计算。

该实现适合演示和初步筛峰；真实测量中需要根据探测器响应、能区和峰宽验证迭代次数及边界行为。

## 峰识别和峰参数

`continuous_wavelet_transform` 使用多个尺度的 Mexican-hat 小波卷积。`detect_peaks_from_cwt` 综合尺度响应、局部极大值、最小间距和信噪比筛选候选峰。小波尺度、阈值系数、峰间距和最小信噪比可由界面或命令行调整。

`refine_peaks` 在局部窗口内以净计数加权质心修正峰位，并估算局部背景扣除后的峰面积、半高宽和信噪比。它不是完整的高斯多峰拟合器，重叠峰和低计数峰需要人工复核。

## 能量刻度

`fit_energy_calibration` 用一次或二次多项式拟合通道与已知能量，至少需要 `degree + 1` 个互异通道点，并返回拟合均方根残差。程序不自动判断刻度是否满足具体仪器或标准的验收要求。

## 核素候选匹配

程序比较峰能量与当前参考库，绝对和相对容差均可配置。显示的“匹配分数”综合能量偏差和参考发射概率，是排序用启发式分数，不是统计置信度、后验概率或自动核素确认结论。

除单峰候选外，`summarize_nuclide_matches` 会为每种核素匹配互不重复的峰和参考线，并综合发射概率覆盖度及能量接近程度生成整谱排序。该结果可以降低共享能量线造成的单峰歧义，但仍不能代替专业人员对本底、逃逸峰、和峰、几何和混合核素的判断。

当前内置库仅用于教学演示。程序支持导入 JSON 映射或包含 `nuclide,energy_kev,intensity` 三列的 CSV。真实使用前应通过 [NNDC NuDat 3](https://www.nndc.bnl.gov/nudat3/) 或项目规定的受控数据库复核核数据版本、能量和发射概率。

## 活度估算

对于已匹配峰，原型依据净峰面积、活时间、用户输入的全能峰效率和发射概率估算活度，并对同核素多个峰取平均。当前没有自动完成不确定度传播、衰变校正、几何修正、自吸收修正或符合相加修正，因此界面和报告均称为“估算”。
