# 算法说明

本文说明当前实现的处理流程及其工程含义，帮助审阅者理解代码，不把原型结果误认为计量结论。

## 输入校验

程序支持 SPE、XLSX、CSV 和 TXT。输入在进入算法前会转换为一维浮点数组，并检查：

- 通道与计数长度相同且非空；
- 数值有限，计数非负；
- 通道顺序单调，重复通道合并；
- SPE 的 `$DATA` 优先按闭区间解释；对于部分导出器使用的上界写法，在实际点数恰好少 1 时兼容读取并记录警告；
- SPE 的 `$MEAS_TIM` 按“活时间、实时间”顺序读取。

## 本底扣除

程序提供两条并存的路径：

1. **自动估计**：`snip_baseline` 在对数变换域内迭代比较局部值与对称邻点均值，用于估计缓慢变化的连续本底。净谱按 `max(counts - baseline, 0)` 计算。
2. **实测本底扣除**：`subtract_background` 读取第二条实测本底谱，按活时间（或实时间）比归一后逐道相减，再在残差上执行 SNIP，以同时去掉环境谱线和样品自身的康普顿连续本底。道数或道址不一致时先线性重采样；落到 0 以下的通道截断到 0 并计数上报。

两种实现的共同简化是：**负值是截断而不是保留符号**，因此扣底越彻底，峰面积的正向偏置越明显；本原型不传播该偏置，也不传播扣底引入的统计不确定度。真实测量中应按探测器响应、能区和峰宽验证迭代次数及边界行为。

## 峰识别和峰参数

`continuous_wavelet_transform` 使用多个尺度的 Mexican-hat 小波卷积。`detect_peaks_from_cwt` 综合尺度响应、局部极大值、最小间距和信噪比筛选候选峰。小波尺度、阈值系数、峰间距和最小信噪比可由界面或命令行调整。

`refine_peaks` 先用净计数加权质心定位，再用 `fit_peak_shape` 做 **高斯 + 线性基线** 的最小二乘拟合（Levenberg–Marquardt，5 个参数：幅度、峰心、σ、基线两项）。峰面积取 `A·σ·√(2π)`，不确定度由线性化协方差矩阵传播；若拟合失败或结果偏离质心估计过多（面积超出 0.2~5 倍、σ 超出 0.3~3 倍、峰心位移超过 1.5σ），自动退回窗口求和并标记不确定度为 0。

这里的面积不确定度只描述该模型的计数统计涨落，不含和峰、自吸收、效率曲线误差等系统项。

`merge_close_peaks` 会把间距小于半个线宽的重复峰合并（低能宽峰常被小波拆成两个极大值），合并时按面积加权定位、面积相加、不确定度按平方和合成。

## 双线成分分解

`decompose_interference` 对已标记为双线的峰做**固定能量多峰拟合**：成分能量取自参考库，只拟合各成分幅度与一个共享宽度，因此对幅度是线性问题，用最小二乘即可稳定求解；共享宽度在一维网格上扫描取残差最小者。

拟合给出每个成分的面积 ± 统计不确定度与占比。是否采信由两道门限决定：

1. **几何门限**：成分间距必须 ≥ 1 个 FWHM。低于该值时拟合在数学上仍可执行，但结果由峰形、能量刻度和统计涨落共同决定，不是数据能支撑的结论；
2. **数值门限**：每个成分面积为正、相对不确定度 < 50%，且成分幅度之间的相关系数 < 0.95。

不满足时仍然显示拟合值，但明确标注“不采信”。原因是：统计量足够时，协方差矩阵会给一个 50/50 的“紧致”分解——那只是把一个叠加峰劈成两半，并非分辨。

## 能量刻度

`fit_energy_calibration` 用一次或二次多项式拟合通道与已知能量，至少需要 `degree + 1` 个互异通道点，并返回拟合均方根残差。程序不自动判断刻度是否满足具体仪器或标准的验收要求。

## 自动能量刻度（混合源）

`auto_calibrate` 把「人工挑两条标准线、再拿其余谱线核对」的过程写成枚举与投票，不需要任何初始刻度：

1. 取最显著的若干峰（默认 36 个），按通道排序；
2. 枚举「两个实测峰 × 两条参考线」的全部组合，解出线性刻度 `(a, b)`，先按斜率区间和可映射能量范围筛掉物理上不可能的候选；
3. 对每个候选做**全局投票**：把库中所有参考线按该刻度映射回通道，落在实测峰上即得分（容差取 `0.55×中位 FWHM` 与能量容差中更严者）。得分按核素汇总为 `覆盖率 × 线数奖励 × 强度加权吻合度`，线数奖励让「整个衰变纲图同时亮起」的候选胜过「偶然对上三条线」的候选；
4. 取初筛前若干名，用其中命中的点在最小二乘下重新拟合刻度，再重新投票，迭代到稳定；
5. 按**精修后**的分数排序，用第二名与第一名的比值判断解是否唯一。

两个实现细节直接决定精度：

- **同一条实测峰只贡献一个拟合点**。双线（如 186 keV 的 U-235/Ra-226）会让两条参考线落在同一峰心，若都参与拟合，等于把同一个质心当成两次独立测量，会把刻度系统性拉偏约 0.3 keV；
- **命中线数必须明显多于拟合参数**。4 条线拟合 2 个参数时，残差几乎必然接近 0，那是过拟合而非吻合；因此少于 5 条命中线、或归一化残差 ≥ 0.35 时标记为「未通过可信度检查」，界面与命令行默认都不采用（命令行需显式 `--allow-unverified-calibration`）。

已知边界：只求线性刻度；至少需要 4 个峰；候选数量随峰数和库线数增长，教学级谱（数十峰、74 条线）在普通台式机上约 0.3–0.5 s。

## 核素候选匹配与双线处理

程序比较峰能量与当前参考库。匹配容差取三项的最大值：

```
容差 = max(绝对容差, 相对容差 × 峰能量, 峰宽容差系数 × 本峰 FWHM)
```

其中 FWHM 由通道宽度乘以能量刻度的局部斜率换算为 keV。加入峰宽项是为了避免“容差比探测器分辨率还窄”这一自相矛盾：若容差远小于 FWHM，落在半高宽内的邻近参考线会被判成完全不匹配。

当两条来自**不同核素**的参考线都落在 `双线判定系数 × FWHM` 以内时，该峰被标记为不可分辨双线：软件列出全部成分及其“等活度发射概率份额”，**不指定主核素、不计算活度**，并在界面和报告里用 `†` 标注。设计依据是：此时峰心的归属由亚 keV 级的质心噪声决定，继续输出单一核素会给出虚假的确定性。典型例子是天然铀样品中 U-235 的 185.715 keV 与 Ra-226 的 186.211 keV；两者的间距小于常规探测器 FWHM，186 keV 峰实际上总是叠加峰。

`summarize_nuclide_matches` 会为每种核素匹配互不重复的峰和参考线，并综合发射概率覆盖度及能量接近程度生成整谱排序。双线峰只按一半强度计入，并在结果中记录为 `ambiguous_lines`，避免“仅靠一条叠加峰”的核素看起来像确定识别。该结果可以降低共享能量线造成的单峰歧义，但仍不能代替专业人员对本底、逃逸峰、和峰、几何和混合核素的判断。

内置库覆盖常见人工刻度源及天然放射性核素（U-238 系：U-235、Ra-226、Pb-210、Th-234、Pb-214、Bi-214；Th-232 系：Ac-228、Pb-212、Bi-212、Tl-208；以及 K-40）。程序支持导入 JSON 映射或包含 `nuclide,energy_kev,intensity` 三列的 CSV。真实使用前应通过 [NNDC NuDat 3](https://www.nndc.bnl.gov/nudat3/) 或项目规定的受控数据库复核核数据版本、能量和发射概率。

## 证书 → 核素库

标准样品源证书只写母体核素与比活度（例如 `238U 158 Bq/kg`），但伽马谱几乎从来看不到母体本身：`238U` 靠 `234Th` 的 63.3/92.4 keV，`232Th` 靠 `228Ac`/`212Pb`/`208Tl`，`226Ra` 靠 `214Pb`/`214Bi`。`certificate.py` 解析证书文本并按 `CERTIFICATE_PROXIES` 展开：

| 证书核素 | 库内实际使用 | 说明 |
|---|---|---|
| 238U | th-234、u-235 | U-235 未单独检定，按天然丰度 A(235U)/A(238U)≈4.6% 随 238U 计入 |
| 232Th | ac-228、pb-212、tl-208、bi-212 | 钍系三条独立支线 |
| 226Ra | ra-226、pb-214、bi-214 | 186 keV 与 U-235 的 185.7 keV 不可分辨，交由双线逻辑标注 |
| 其他 | 自身 | 如 40K、60Co、137Cs |

这样得到的库只包含证书能解释的谱线（典型 6 项证书 → 12 种核素、44 条线），相对内置库的 28 种、74 条线大幅收缩；证书里没有的核素不会再出现在候选名单里。库中缺失的替代核素（例如需要 1001 keV 时的 `234mPa`）会被列出来而不是静默丢弃。

文本解析容忍常见写法（`238U：158`、`U-238 = 158 Bq/kg`、`K40 535`），并会顺带读取证书的定值日期与样品质量，用质量把 Bq/kg 换算成总活度，供效率刻度使用。

### 证书文件读取

`read_certificate_file` 直接读 `.docx`（解压 `word/document.xml` 后按段落还原，不依赖 python-docx）、`.xlsx`（解压共享字符串与首个工作表）、`.pdf`（解压 FlateDecode 流并按 `Tj/TJ` 取文本，扫描件会明确报错）以及 `.txt/.csv`（依次尝试 UTF-8/UTF-16/GB18030/Big5）。图片证书需要 OCR，离线不处理，会提示改用同批文件里的 Word 版。

日期解析有优先级：**含“检定/定值/标定/证书”的行**优先于测量日期行。一份实验说明里同时出现“测试日期2022年11月11日”和“检定时间1995年1月31日”时，只有后者才是活度的基准日期。

### 衰变校正

证书活度是针对**定值日期**的，谱是**测量日期**测的。`decay_factor` 用 `A(t) = A₀·2^(-Δt/T½)` 把每个核素校正到测量日期，半衰期取 `HALF_LIVES`（单位为年）：

- 短寿命核素的差别是数量级的：Co-60（5.27 a）从 1995 年定值到 2022 年测量只剩 **2.6%**，Cs-137 剩 52.7%；
- 长寿命的（U-238、Th-232、Ra-226、K-40）系数 ≈1，可忽略。

校正作用在**证书核素**（母体）上，而不是其子体：Ra-226 与其子体 214Pb/214Bi 处于长期平衡，二者随 Ra-226 的 1600 年半衰期一起变化，用子体自己的短半衰期去校正反而会错。

## 活度估算

对于已匹配峰，原型依据净峰面积、活时间、用户输入的全能峰效率和发射概率估算活度，并对同核素多个峰取平均。当前没有自动完成不确定度传播、衰变校正、几何修正、自吸收修正或符合相加修正，因此界面和报告均称为“估算”。
