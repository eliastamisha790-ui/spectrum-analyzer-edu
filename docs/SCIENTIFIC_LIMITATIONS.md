# 科学与使用限制

## 定位

本项目用于课程学习、算法演示、软件工程交流和作品集展示，不是商品化仪器软件，也没有经过计量检定、型式评价、法规认证或独立实验室验证。

## 不适用场景

不得仅依据本软件输出作出以下决定：

- 放射源识别、现场处置或辐射安全决策；
- 医疗诊断、治疗计划或剂量学结论；
- 环境监测达标、监管申报或司法鉴定；
- 仪器校准证书、标准物质定值或其他计量结论。

## 已知限制

- 核素参考库规模很小，版本没有与受控核数据库自动同步。
- 匹配分数是启发式排序指标，不表示统计置信度。
- 峰搜索没有对所有探测器类型、能区、计数率和重叠峰情形进行验证。
- 活度估算依赖用户提供的探测器效率曲线和正确的活时间。
- 当前未传播峰面积、效率、发射概率和时间的不确定度。
- 当前未自动执行衰变、几何、自吸收、死时间扩展、符合相加等修正。
- 电子表格解析关注常见表格结构，复杂公式、宏或厂商专用布局可能不兼容。

## 推荐的真实工作流

如将算法用于真实实验，应使用授权且可追溯的数据集，记录仪器和测量几何，使用带证书的标准源验证能量、效率和峰面积，并由具备资格的人员选择适用的标准、修正模型及验收阈值。
