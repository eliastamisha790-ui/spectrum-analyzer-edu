# 数据政策

## 仓库中可以包含的内容

- 由项目代码生成、明确标注且可复现的合成数据；
- 作者有权公开的源代码、测试、截图和说明文档；
- 不含个人信息、仪器序列号、账号、密钥或绝对本机路径的示例输出。

## 仓库中不包含的内容

- 来源、授权或署名不清楚的实测谱和电子表格；
- 第三方实验数据、课程资料或单位内部数据；
- EXE、`_internal` 等可由源码重新生成的大型打包文件；
- API 密钥、账号凭证、个人联系方式及本机绝对路径；
- 用户运行时生成的报告和效率模型。

`examples/synthetic_co60.spe` 是固定随机种子生成的教学谱，不代表任何真实设备或放射源测量。
